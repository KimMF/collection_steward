# Checkout means assignment to a show, actor, and character

In Collection Steward, checkout has a specific meaning: a collection asset has
been pulled for a production and assigned to a particular actor and character.

Production checkout is not a general location change and is not donation
intake. Active production checkouts will eventually generate the set-strike
triage list. Set strike will check those assets back in and record their next
physical destination or unfinished work.
