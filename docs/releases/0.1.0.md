# Collection Steward 0.1.0 — Pilot Baseline

This release preserves the initial working Collection Steward pilot before
development of user-friendly asset intake and production checkout.

## Current capabilities

- Public read-only asset display
- User login and logout
- Authenticated write controls
- Asset categories and free-text size descriptions
- Asset photographs with thumbnail and expanded display
- Assignment and removal of reusable tags
- Set-strike actions with temporary staging locations
- Pending and completed strike-action status
- Preserved strike-action history
- Selection of existing assets for viewing and strike work

## Known limitations

- Assets are entered directly through the database
- Photograph directories, filenames, and database links are managed manually
- There is no incoming-donation entry screen
- There is no production, cast, checkout, or check-in structure
- There is no permanent rack, bin, or location model
- Deployment remains manual

## Planned next development

- Simple incoming-donation entry suitable for a nontechnical user
- Photograph upload managed by the application
- Production and cast records for *Steel Magnolias*
- Checkout of collection assets to an actor and character
- Set-strike triage generated from active production checkouts
